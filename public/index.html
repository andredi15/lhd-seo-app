    SCORING & SOURCES

    Know what the score means.

    A prioritization tool

    The SEO Optimization Score is a weighted heuristic, not a Google ranking score. It helps prioritize observed page issues. It does not predict rankings, traffic, or revenue.

    Transparent weighting

    Search Intent & Relevance 20%; Content Quality & Topic Coverage 20%; On-Page SEO 20%; Technical/Page Structure 15%; Internal Linking & Site Signals 10%; Local SEO Signals 10% for local queries; Conversion/Trust Signals 5%. For non-local queries, the local weight is split equally between intent and content.

    A noindex or none directive caps the score at 35. Each report shows its individual category checks. Keyword scores use their own placement and intent formula and do not include all technical checks.

    Domain Competitive Score

    Domain Analysis uses a separate score: Topical Coverage 25%; Site Architecture 20%; Content Quality & Depth 20%; Internal Linking 15%; Local SEO Coverage 10%; Technical Consistency 10%. For non-local sites, topical coverage becomes 30% and content becomes 25%. The score describes a bounded sample, not domain authority or rankings.

    Observed versus inferred

    Titles, metadata, headings, static text, links, images, HTTP details, and schema are extracted from the supplied URLs. Query intent, geographic intent, topical breadth, trust wording, and content gaps are explicitly labeled inferences. The English-language rules may miss natural synonyms, unknown place names, and content that depends on JavaScript.

    Missing alt attributes and empty alt attributes are separate: empty alt text may be correct for decorative images. Word count and character lengths are diagnostic cues, not targets. Page mode does not fetch link destinations or image contents. Domain mode follows eligible internal HTML links within its limit. Metadata is reported as declared, not verified.

    AI editorial layer

    When configured, the backend uses OpenAI’s Responses API with Structured Outputs. Retrieved page text is untrusted input; AI is given no tools. Every accepted suggestion must carry an exact quotation from a retrieved source. AI cannot overwrite facts or scores. Citation validation does not prove that an interpretation is correct: review generated suggestions before publishing.

    External data

    The optional PageSpeed Insights integration provides labeled Google Lighthouse lab results under Technical. Real-user Core Web Vitals, rankings, backlinks, traffic, Search Console and Business Profile data are not measured by that integration. Fetch duration measures a single HTML response from this server, not browser loading performance.

    Scope and privacy

    Page Analysis retrieves the supplied target and competitor pages. Domain Analysis discovers internal pages and XML sitemaps with a 10, 25 or 50 HTML URL request limit per domain, including redirects and errors. Discovery counts are not indexed-page counts; click depth and orphan-like signals use only observed links. Reports are stored locally in this browser, up to ten reports. Configuring OpenAI sends selected extracted page text and keywords to that API; the API key stays on the server.
